# 本单位定制材料（按需放入）

此目录专门放**你本单位专属**的文字材料。放进来的 `.md` 文件会被 skill 在写作时**优先参考**（优先级仅次于你在对话里直接贴出的材料）。

## 可以放什么

- **范文 / 样例**：本单位总结、汇报、请示等成稿（脱敏后）
- **术语表**：本单位机构名称、职务称谓、固定表述、常用称呼
- **格式要求**：红头格式、标题写法、落款规范、特定文种模板
- **语言习惯**：领导 / 单位偏好的措辞、语气、常用套话

## 怎么放

- 任意 `.md` 文件，文件名自定，如 `fanwen-zongjie.md`、`shuyu.md`、`geshi.md`
- 一个文件一个主题，方便按需查阅
- 不要放涉密、敏感内容

## 优先级（从高到低）

1. 用户在对话中直接贴出的材料
2. 本目录下的单位自定义文件
3. 插件自带通用规范（`wenzhong.md` / `style.md` / `format.md`）

> 本目录为空时，skill 直接使用通用规范，无需任何操作。
