# 各文种写作指南

> 写作时先查对应文种，按"结构框架"搭提纲，再参考"写作要点"和"范文片段"填充。

## 文种选择速查

| 我要…… | 用这个文种 |
|--------|-----------|
| 回顾一段时间的工作、总结成绩与问题 | 工作总结 |
| 向上级反映工作进展、请求指示 | 工作汇报（汇报材料） |
| 个人向组织汇报履职情况 | 述职报告 |
| 向上级请求批准、指示某件事 | 请示 |
| 向上级汇报工作、反映情况、答复询问 | 报告 |
| 部署工作、告知事项、印发文件 | 通知 |
| 表彰先进、批评错误、传达精神 | 通报 |
| 与不相隶属单位商洽、询问、答复 | 函 |
| 记载会议情况和议定事项 | 会议纪要 |
| 会议发言、动员部署 | 讲话稿 |
| 对某项工作/问题深入调查研究 | 调研报告 |
| 推广可复制的做法经验 | 经验交流材料 |
| 介绍先进个人/集体的突出事迹 | 事迹材料 |
| 对重要问题提出见解和处理办法 | 意见 |

## 一、工作总结

**用途**：回顾一段时期的工作，肯定成绩、找出问题、总结经验、明确方向。

**结构框架**：
```
标题（单位/岗位 + 时间 + 文种，如《××科2026年上半年工作总结》）
一、基本情况（总起，一两句概括）
二、主要工作及成效（分条列，核心部分）
三、存在问题和不足（真实、不敷衍）
四、经验体会（可选）
五、下一步工作打算
```

**写作要点**：
- 以数据说话：做了多少事、达到什么指标、同比/环比变化。
- 突出亮点：把最有分量的 1—3 项工作放前面重点写。
- 问题要真实具体，不写"还存在一些不足"这类空话。
- 经验要可复制、可推广，不是口号。

**常见误区**：流水账（按日期罗列）、报喜不报忧、套话空话多、面面俱到没重点。

**范文片段（主要工作及成效）**：
> 二、主要工作及成效
> （一）稳步推进重点项目建设。全年实施重点项目〔待补充：×〕个，完成投资〔待补充：×〕万元，其中〔项目名〕于×月建成投用，预计年新增产值〔待补充〕万元。
> （二）持续优化营商环境。推行〔待补充：具体措施〕，办事环节由〔×〕个精简至〔×〕个，办理时限压缩〔×〕%。年内新增市场主体〔×〕户，同比增长〔×〕%。

## 二、工作汇报（汇报材料）

**用途**：向上级反映工作进展、成效、问题和建议，供上级了解情况、作出决策。

**与总结的区别**：汇报偏"现在进行时"，强调进展和问题、请求指示；总结偏"完成时"，强调回顾和经验提炼。

**结构框架**：
```
一、工作开展情况（截至×××）
二、主要做法及成效
三、存在的困难和问题
四、下一步打算及请示事项
```

**写作要点**：
- 开头交代依据/背景（"根据××部署""按照××要求"）。
- 重点写进展到哪一步、取得什么效果、还有什么困难。
- 需要上级协调解决的，明确写进"请示事项"。
- 语气谦敬、实事求是。

---

## 三、述职报告

**用途**：个人（领导干部/工作人员）向组织、群众报告履职情况。

**结构框架**：
```
一、基本情况（岗位及职责）
二、履职情况（按"德、能、勤、绩、廉"或按分管工作分述）
三、存在的不足
四、努力方向
```

**写作要点**：
- 以"我"为视角，突出个人履职，避免写成单位工作总结。
- "绩"是重点：本人主抓了哪些事、取得什么成效，用具体事例和数据。
- "廉"部分简述遵规守纪情况，点到为止、实事求是。
- 不足要真诚，不避重就轻。

---

## 四、请示

**用途**：向上级机关请求指示、批准。**一文一事，请求上级答复。**

**结构框架**：
```
标题（关于×××的请示）
主送机关（只能一个）
正文：缘由（为什么要请示，理由充分）→ 事项（请求批准什么，明确具体）→ 结语（妥否，请批示）
落款（单位 + 日期）
```

**写作要点**：
- 一文一事，不能一个请示夹带多个事项。
- 缘由充分、事项明确，避免让上级无法答复。
- 请示与报告分开，请示必须有结语"妥否，请批示"等。
- 主送机关只能一个，抄送按需。

**范文片段**：
> 关于解决××办公用房紧缺问题的请示
> ××局：
> 我单位现有工作人员〔×〕人，办公用房〔×〕平方米，人均不足〔×〕平方米。随着〔待补充：具体原因〕，办公用房已难以满足正常工作需要。
> 为此，拟申请将〔待补充：具体房源〕划归我单位使用，面积约〔×〕平方米。
> 妥否，请批示。
> ××单位
> 2026年9月28日

## 五、报告

**用途**：向上级汇报工作、反映情况、答复上级询问。**一般不要求上级答复**（与请示的本质区别）。

**结构框架**：
```
标题（关于×××的报告）
主送机关
正文：缘由 → 主要情况 → 结语（特此报告）
落款
```

**写作要点**：
- 报告中不得夹带请示事项（需要批准的事项单独写请示）。
- 情况真实、条理清楚。
- 答复询问类的报告要有针对性，先引上级来文/来电再逐条答复。

---

## 六、通知

**用途**：部署工作、告知事项、印发文件、批转转发文件。

**结构框架**：
```
标题（发文机关 + 事由 + 通知，如《关于做好××工作的通知》）
主送机关
正文：缘由（为什么发）→ 事项（做什么，分条）→ 要求（怎么做、何时完成）
落款
```

**写作要点**：
- 事项明确、要求具体、时限清楚。
- 部署工作类要写清：做什么、谁来做、何时做、做到什么标准。
- 会议通知要素齐全：时间、地点、参会人员、议题、要求。

---

## 七、通报

**用途**：表彰先进、批评错误、传达重要精神或情况。

**结构框架**：
```
标题（关于×××的通报）
正文：事实（什么事）→ 分析/评价 → 决定（表彰/批评/要求）→ 结尾（特此通报）
```

**写作要点**：
- 事实准确、定性恰当。
- 表彰要写明先进事迹和值得学习之处；批评要指出错误、危害和教训。
- 语气庄重，用词分寸得当。

---

## 八、函

**用途**：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

**结构框架**：
```
标题（关于×××的函 / 复函）
主送机关
正文：缘由 → 事项 → 结语（特此函达 / 请予函复）
落款
```

**写作要点**：
- 用于不相隶属机关之间，语气平等、商洽，不用"请示""报告"。
- 一事一函，事项清楚。
- 复函要先引原函（"你单位《关于××的函》收悉"）。

---

## 九、会议纪要

**用途**：记载会议主要情况和议定事项。

**结构框架**：
```
标题（××会议纪要）
开头：会议概况（时间、地点、主持、参会、议题）
主体：会议主要精神 / 议定事项（分条）
结尾：落实要求
```

**写作要点**：
- 只写议定事项和共识，不写讨论过程中的分歧细节（确需保留的除外）。
- 议定事项要明确"谁负责、何时完成、什么标准"。
- 用"会议认为、会议指出、会议决定、会议议定"等规范用语。

---

## 十、讲话稿

**用途**：领导在会议、活动上的发言。按性质分：部署性、总结性、动员性、致辞类。

**结构框架**：
```
开场：称呼 + 点题（为什么开这个会/讲话）
主体：分点展开（统一认识 / 部署任务 / 提出要求）
结尾：号召、要求
```

**写作要点**：
- 符合讲话人身份、语气和场合，口语化但不失庄重。
- 部署性讲话要"讲清意义、讲明任务、讲实要求"。
- 善用短句、排比增强气势，但不过度。
- 开头要破题、结尾要有号召力。

---

## 十一、调研报告

**用途**：对某项工作、某个问题深入调查后形成的书面报告。

**结构框架**：
```
标题（关于×××的调研报告）
一、调研基本情况（目的、对象、方法、时间）
二、现状与成效
三、存在问题及原因分析
四、对策建议（重点）
```

**写作要点**：
- "问题—原因—对策"一一对应，对策要可操作。
- 用数据和事例支撑判断，不主观臆断。
- 对策建议是核心价值，要具体、有针对性。

---

## 十二、经验交流材料

**用途**：在会议、培训等场合介绍可复制、可推广的做法。

**结构框架**：
```
标题（提炼成一句经验，如《推行××机制 破解××难题》）
一、背景与动因（为什么做）
二、主要做法（分条，重点）
三、取得的成效
四、经验启示
```

**写作要点**：
- 标题要亮，直接点出经验。
- 做法要"可复制"，突出机制、方法而非简单罗列。
- 成效用数据佐证。

---

## 十三、事迹材料

**用途**：介绍先进个人或集体的突出事迹，用于评先评优、宣传。

**结构框架**：
```
标题（姓名/单位 + 事迹概述）
一、基本情况（人物/单位简介）
二、主要事迹（分条，以具体事例支撑）
三、荣誉与影响
```

**写作要点**：
- 用具体事例说话，避免空泛赞美。
- 突出"人无我有、人有我优"的闪光点。
- 细节真实，不拔高、不虚构。

---

## 十四、意见

**用途**：对重要问题提出见解和处理办法（可上行、下行、平行）。

**结构框架**：
```
标题（关于×××的意见）
正文：缘由 → 意见内容（分条）→ 结尾（提出要求/执行意见）
```

**写作要点**：
- 内容具体，具有指导性、可操作性。
- 分条表述，条理清晰。
- 下行意见结尾常加"请结合实际认真贯彻执行"。
