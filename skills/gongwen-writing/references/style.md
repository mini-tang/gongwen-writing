# 语言与表述规范

## 一、总体要求

机关文风六个字：**庄重、准确、朴实、精炼、规范**。

- **庄重**：用书面语，不用口语、网络语、俏皮话。
- **准确**：概念、范围、程度、时间、数字要精确，不模棱两可。
- **朴实**：不堆砌辞藻，不空喊口号，用"事"和"数"说话。
- **精炼**：短句为主，删掉可有可无的字词。
- **规范**：用词、标点、格式符合规范用法。

## 二、常用公文套语

### 开头
- 依据式："根据……""按照……""为深入贯彻落实……"
- 目的式："为进一步加强……""为切实抓好……"
- 引述式："你单位《关于……的请示》（×字〔2026〕×号）收悉"

### 过渡
- "现将有关情况报告如下""现将有关事项通知如下""现就……提出如下意见"

### 结尾
| 文种 | 结语 |
|------|------|
| 请示 | "妥否，请批示""以上请示，请予审批" |
| 报告 | "特此报告" |
| 通知 | "特此通知" |
| 函 | "特此函达""请予函复" |
| 通报 | "特此通报" |

## 三、数字用法（GB/T 15835—2011 要点）

- **用阿拉伯数字**：公历日期（2026年9月28日）、年代（上世纪90年代）、统计数字（增长8.5%、第3季度）。
- **用汉字**：概数（三四十人、十来天、七八百人）、"一"字头的不定数（一律、一并）。
- 分数、百分比、倍数用阿拉伯数字。
- "增加到原来的2倍"与"增加了1倍"含义不同，注意区分。
- 多位整数不能断行书写。

## 四、标点要点

- 引号内套引号：先双引号，内层用单引号。
- 书名号内套书名号：双书名号内用单书名号。
- 连接号：表起止用"—"（2026年1—6月）；表数值范围用"～"（10～20人）。
- 顿号用于并列词语，逗号用于分句；并列的"大项"之间用逗号，内部"小项"用顿号。

## 五、常见易错词（务必分清）

| 易混 | 辨析 |
|------|------|
| 截至 / 截止 | 截至＝到某时为止（截至9月底）；截止＝到期限停止（报名截止） |
| 制定 / 制订 | 制定＝定下来（制定政策）；制订＝创制拟定（制订计划） |
| 部署 / 布置 | 部署用于重要工作（部署任务）；布置用于具体事务（布置会场） |
| 反映 / 反应 | 反映＝把情况告诉上级；反应＝对外界刺激的回应 |
| 必须 / 必需 | 必须＝一定要（副词）；必需＝一定要有（动词/形容词） |
| 权力 / 权利 | 权力＝职权、强制力；权利＝依法享有的权益 |
| 启用 / 起用 | 启用＝开始使用（启用新公章）；起用＝重新任用人员 |
| 以至 / 以致 | 以至＝表范围延伸；以致＝引出不好的结果 |
| 决不 / 绝不 | 决不＝坚决不；绝不＝绝对不 |
| 制定 / 拟定 | 拟定＝草拟、初拟 |
| 会商 / 协商 | 会商＝会同商量（机关间）；协商＝共同商量 |
| 报经 / 报请 | 报经＝报上级经批准；报请＝报上级请求 |

## 六、常见病句类型

1. **成分残缺**：缺主语（"通过学习，使我认识到……"——删"使"或"通过"）
2. **搭配不当**：动宾不搭配（"完成工作水平"应为"提高工作水平"）
3. **句式杂糅**：两种句式混用（"目的是为了……"删其一）
4. **语序不当**：修饰语位置错乱
5. **重复啰嗦**："彻底根治""目前的当务之急""亲自莅临"
6. **指代不明**："这""其""该"指代不明确

## 七、政治表述（原则性要求）

- **以最新权威表述为准**：政治概念、政策提法要与权威文件、官方发布保持一致，不自我发挥、不凭印象。
- **不臆造提法**：不编造政策名称、文件文号、领导讲话。
- **把握分寸**：表述成绩不夸大、谈问题不回避、讲责任不推诿。
- 涉及重大、敏感提法时，建议用户核对权威原文后再定稿。

## 八、称谓与语气

- 对上级：谦敬、请示（"恳请""报请""请予"）。
- 对下级：明确、要求（"必须""要切实""请抓好落实"）。
- 对平级/不相隶属：商洽（"请予支持""请予函复"）。
- 对群众：通俗、亲和，少用生僻术语。
