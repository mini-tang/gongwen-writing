# 公文版式规范（GB/T 9704—2012 要点）

以下为党政机关公文格式的常用要点，供排版时对照。日常事务性文稿（总结、汇报、述职等）可适当从宽，正式公文（红头文件）应严格执行。

## 一、用纸与版心

- **用纸**：A4（210mm × 297mm）
- **版心尺寸**：156mm × 225mm
- **页边距**：上 37mm ± 1mm，下 35mm ± 1mm，左 28mm ± 1mm，右 26mm ± 1mm
- **每页行数**：一般每面排 22 行，每行排 28 个字（Word/WPS 中对应"每页 22 行、每行 28 字"，行距通常为固定值 28～30 磅）

## 二、字体字号（最常用，务必记牢）

| 要素 | 字体 | 字号 |
|------|------|------|
| 标题（文头大标题） | 小标宋体 | 二号 |
| 正文 | 仿宋体 | 三号 |
| 一级标题（一、） | 黑体 | 三号 |
| 二级标题（（一）） | 楷体 | 三号 |
| 三级标题（1.） | 仿宋体（可加粗） | 三号 |
| 四级标题（（1）） | 仿宋体 | 三号 |
| 发文字号、成文日期、落款 | 仿宋体 | 三号 |

> 小标宋体在 Word 中名为"方正小标宋简体"，若没有可临时用黑体替代。

## 三、结构层次序数

正文结构层次序数依次为：

```
一、××××      （黑体，顶格）
（一）××××     （楷体，顶格或空两字）
1.××××        （仿宋，空两字）
（1）××××      （仿宋，空两字）
```

- 序数严格按此顺序使用，**不得跳级或颠倒**。
- "一、"后用顿号；"（一）"后不加标点；"1."后用小圆点；"（1）"后不加标点。
- 层数少时，一般只用到"一、"和"（一）"两层即可。

## 四、标题拟制

- **完整式**：发文机关名称 + 事由 + 文种，如《××市××局关于加强××工作的通知》
- 标题居中对齐，回行时词意完整、排列对称、长短适宜，不割裂词意。
- 除法规、规章名称加书名号外，标题一般**不用标点符号**。

## 五、发文字号、主送机关、落款

- **发文字号**：机关代字 + 〔年份〕 + 序号，如 `×政发〔2026〕12号`（年份用六角括号〔〕）
- **主送机关**：标题下空一行，顶格，机关之间用顿号，同级同类后用逗号，最后用冒号。
- **成文日期**：用阿拉伯数字，如 `2026年9月28日`，右空四字。
- **发文机关署名**：在成文日期上一行居中排布，加盖印章。

## 六、Word / WPS 排版步骤（实用）

1. 页面设置：A4，上下 3.7cm/3.5cm，左右 2.8cm/2.6cm。
2. 标题：二号小标宋，居中，回行对齐。
3. 正文：三号仿宋，首行缩进 2 字符。
4. 行距：固定值 28～30 磅。
5. 一级标题黑体、二级标题楷体、三级仿宋加粗。
6. 落款：成文日期右空四字，署名居中。
7. 页码：四号半角宋体阿拉伯数字，单页居右空一字、双页居左空一字。

## 七、常见格式错误

- 标题字号过大或用加粗仿宋当标题
- "一、"用楷体、"（一）"用黑体等字体错配
- 层次序数跳级（直接"一、"后接"1."）
- 成文日期用汉字（"二〇二六年"）——规范要求阿拉伯数字
- 发文字号用中括号〔〕写错成【】或[]
